# Privacy policy

_Last updated: 2026-11-14_

This policy covers the DVD Screensaver plugin for Claude Code
(`dvd-screensaver`).

## What the plugin reads

To show the latest tool calls under the logo, the plugin reads the arguments
of each tool call Claude makes in your session: the command, file path, URL,
search query, prompt or description. These can contain whatever you or Claude
put in them, including names, email addresses or other personal data.

## What it keeps

The last three of those lines, each collapsed onto one line, are kept in the Claude
Code session's memory only so they can be drawn on screen. They are cleared at
the start of every turn and are gone when the session ends. The plugin also
keeps the logo's position and color the same way.

The plugin does not write anything to disk.

## What it sends

Nothing. The plugin makes no network requests and has no skills, MCP servers
or connectors. No data leaves your machine because of it, and there is no
service that receives or retains data.

## Children

The plugin is a general-purpose add-on for Claude Code and is not aimed at
users under 18.
