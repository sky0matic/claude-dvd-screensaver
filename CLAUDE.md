# dvd-screensaver

A Claude Code plugin (a mod): a bouncing DVD logo that fills the area above the
prompt while a long turn runs. Terminal only.

## Layout

- `plugin/` is the shipped plugin. All the code is in `plugin/hooks/register.tsx`;
  the `$.state` contract is in `plugin/types/index.d.ts`.
- The repo root is development tooling and the marketplace manifest
  (`.claude-plugin/marketplace.json`, source `./plugin`).
- Never add dev tooling inside `plugin/`: the plugin directory puts a policy
  hold on a lockfile, a `package.json`, scripts of other types (like git hooks),
  a `CLAUDE.md` and setup commands in the README that ships.

## Checking changes

- Run `npm run check` before committing: type-check, `claude plugin validate`
  on the marketplace and the plugin, and `claude plugin test plugin`. The git
  pre-commit hook in `.githooks/` runs it too; `npm install` turns the hook on.
- Tests live in `plugin/tests/*.test.tsx` and use `claude-code/testing`. Use
  `mock.clock(on)` for anything on a timer, never real waits.
- To try it live: `claude --plugin-dir ./plugin`

## Things not to change by accident

- The plugin `name` (`dvd-screensaver`) is permanent once published: renaming
  it breaks existing installs. Use `displayName` for a label change.
- `plugin/.claude-plugin/icon.png` is taken as the directory listing icon only
  on the first submission; changing it later does nothing there.
- `plugin/.claude-plugin/types/` is generated by Claude Code when it loads the
  plugin. Don't edit it; it's gitignored.
- `dev/` holds local scripts that render the demo GIF and the icon. It's
  gitignored. If the logo in `register.tsx` changes, keep the copies in
  `dev/make_gif.py` and `dev/make_icon.py` in step.
