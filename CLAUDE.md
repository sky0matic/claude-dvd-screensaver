# dvd-screensaver

A Claude Code plugin (a mod): a bouncing DVD logo that fills the area above the
prompt while a long turn runs. Terminal only. All the code is in
`hooks/register.tsx`; the `$.state` contract is in `types/index.d.ts`.

## Checking changes

- Run `npm run check` before committing: type-check, `claude plugin validate .`
  (plugin and marketplace manifests) and `claude plugin test .`. The git
  pre-commit hook in `.githooks/` runs it too; `npm install` turns the hook on.
- Tests live in `tests/*.test.tsx` and use `claude-code/testing`. Use
  `mock.clock(on)` for anything on a timer, never real waits.
- To try it live: `claude --plugin-dir .`

## Things not to change by accident

- The plugin `name` (`dvd-screensaver`) is permanent once published: renaming
  it breaks existing installs. Use `displayName` for a label change.
- `.claude-plugin/icon.png` is taken as the directory listing icon only on the
  first submission; changing it later does nothing there.
- `.claude-plugin/types/` is generated by Claude Code when it loads the plugin.
  Don't edit it; it's gitignored.
- `dev/` holds local scripts that render `assets/demo.gif` and the icon. It's
  gitignored and not part of the plugin.
- If the logo in `hooks/register.tsx` changes, keep the copies in
  `dev/make_gif.py` and `dev/make_icon.py` in step.
